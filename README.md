# FINstituteGitHubWorkshop

### Links to Necessary Software for Workshop:
#### Git:
https://git-scm.com/install/

#### R (4.6.1 or most current):
##### Windows:
https://cran.r-project.org/bin/windows/base/

##### Mac:
https://cran.r-project.org/bin/macosx/

##### Ubuntu/Debian:
```bash
sudo apt update\
sudo apt-get install r-base
```
##### Fedora:
```bash
sudo dnf install R
```
#### RStudio:
##### Windows/Mac/Linux:
https://docs.posit.co/ide/user/download.html

##### Ubuntu/Debian (Latest as of 25/10/2026):
```bash
sudo dpkg -i rstudio-2026.09.0-174-amd64.deb\
sudo apt-get install -f
```
##### Fedora:
```bash
sudo dnf install rstudio-2026.09.0-174-x86_64.rpm
```
